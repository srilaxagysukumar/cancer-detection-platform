How this works: the trained model (a soft-voting ensemble of logistic regression, random forest and gradient boosting) was exported from Python to model.json, and engine.js runs the same arithmetic in your browser. Nothing you type is sent anywhere, and there is no server to wake up. Explanations use the SHAP permutation method.

The full project (reproducible DVC pipeline, FastAPI backend, Streamlit dashboard, Docker, tests) is in the GitHub repository.
